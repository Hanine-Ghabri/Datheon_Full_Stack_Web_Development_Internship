## 🎀 About This Repo

Hi! 👋 This is my submission for the **Datheon Full Stack Web Development Internship**. Everything here is built with plain **HTML, CSS, and JavaScript**: no frameworks, no build step, nothing to install. Just open a file and it works. ✨

## 🌷 Task 1: Personal Portfolio

A one-page site that shows off my projects, skills, and certifications.

- 🌙 Light and dark theme toggle (remembers your choice)
- 📱 Responsive layout with a hamburger menu on phones
- 🪟 Project cards that open a details pop-up
- ✨ Cursor glow and scroll-fade effects
- ♿ Accessible: keyboard support and reduced-motion friendly

👉 **Open:** `task1/portfolio.html` · 📖 [Read more](./task1/README.md)

---

## ✅ Task 2: Taskboard

A productivity app where your tasks stay put, even after a page reload.

- ➕ Create, edit, complete, and delete tasks
- 🏷️ Categories: Work, Personal, Study
- 📅 Due dates, with overdue tasks flagged
- 🔎 Filter by status and category, plus search
- 🖱️ Drag and drop to reorder
- 💾 Saved in your browser with `localStorage`
- 🌗 Light and dark mode that follows your system

👉 **Open:** `task2/index.html` · 📖 [Read more](./task2/README.md)

## 🚀 Try It Yourself

```bash
git clone https://github.com/Hanine-Ghabri/Datheon_Full_Stack_Web_Development_Internship.git
cd Datheon_Full_Stack_Web_Development_Internship
```

Then open `task1/portfolio.html` or `task2/index.html` in your browser. 🎉

<details>
<summary>💡 Want to run it on a local server?</summary>

<br>

```bash
python -m http.server 8000
```

Then visit:
- `http://localhost:8000/task1/portfolio.html`
- `http://localhost:8000/task2/`

</details>

<details>
<summary>🌐 Want to put it online with GitHub Pages?</summary>

<br>

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. After a minute or two, your projects will be live at:
   - `https://hanine-ghabri.github.io/Datheon_Full_Stack_Web_Development_Internship/task1/portfolio.html`
   - `https://hanine-ghabri.github.io/Datheon_Full_Stack_Web_Development_Internship/task2/`

</details>
